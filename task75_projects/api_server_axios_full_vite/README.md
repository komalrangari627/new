# API Server (Axios + Vite + CORS + Object-Assign)

## 🚀 How to Run

1️⃣ Unzip the folder  
2️⃣ Open terminal inside the folder  
3️⃣ Install dependencies:
   ```bash
   npm install
   ```

4️⃣ Run the server:
   ```bash
   npm run dev
   ```

✅ Server runs at: http://localhost:5005  
Frontend (Vite): http://localhost:5173
