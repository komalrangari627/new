# React Vite Client (preconfigured)

This is a simple React + Vite frontend configured to call the backend at http://localhost:5005

How to run:

1. unzip
2. cd react_client_vite
3. npm install
4. npm run dev

The app uses TailwindCSS (already configured). If Tailwind classes don't appear, ensure you ran `npm install` which installs tailwind and postcss devDependencies.
